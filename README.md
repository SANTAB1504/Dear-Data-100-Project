# Dear Data 100 Project

Project for IN1007

This will outline my initial ideas for the project.

An interactive data visualization built in processing. It will track 100 combat encounter from Delta rune to explore difficulty, tactical choices, and final health points.

## The 100 Observations

Encounter Name of boss or enemy facing player

Difficulty(1-5)

Most Used Action: The dominant strategy used Act defend, SPARE/ACT, fight.

Final HP We will assume no healing

## Visual Language and Key

I will drift away from standard charts and use a custom Heart Glyphs

Heart Colour difficulty Cyan Blue easy and extreme red for hard

Border Style Gold Shield for defend, White for ACT/SPARE DarkOutline for attack.
